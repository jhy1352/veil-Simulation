
# Commercial Plans: Free & Paid AI Tier Architecture

| :--- | :--- | :--- |

## 2. API Call Economy (Constitution Article 29)
- Deterministic logic (Dice, Stats, Filtering, Search, Validation) is handled 100% locally by the Engine without calling LLM APIs.
- Gemini API calls are strictly reserved for narrative reasoning, character psychological depth, and causal synthesis.
