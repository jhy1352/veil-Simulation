## 2. 런타임 프롬프트 빌드 구조 및 데이터 레이아웃

전송되는 원천 프롬프트는 런타임 엔진 상에서 다음과 같은 결정론적 우선순위와 아키텍처 흐름에 의해 하나로 결합 및 가공되어 Gemini API의 `GenerateContentRequest` 바디 내 `contents` 파트와 `systemInstruction` 필드로 주입됩니다.

```
+-----------------------------------------------------------------------------------------+
|                                     SYSTEM PROMPT                                       |
|  - masterPrompt.ts 내 MASTER_SYSTEM_INSTRUCTION (헌법 수칙 제1조 ~ 제11조 및 로케일 규격)     |
+-----------------------------------------------------------------------------------------+
                                             ↓
+-----------------------------------------------------------------------------------------+
|                                     USER / CONTEXT                                      |
|  - [TRPG Campaign Context] (세계관 설정, 백연화 주인공 프로필, 소장품, 능력치 상태)       |
+-----------------------------------------------------------------------------------------+
                                             ↓
+-----------------------------------------------------------------------------------------+
|                                  CONVERSATION HISTORY                                   |
|  - Turn-by-Turn User/Model 교차 이력 직렬화 (인과적 서사 영속성 보장)                         |
+-----------------------------------------------------------------------------------------+
                                             ↓
+-----------------------------------------------------------------------------------------+
|                                 LATEST PLAYER INPUT                                     |
|  - 해당 턴의 플레이어 실제 행동 Intent 선언                                               |
+-----------------------------------------------------------------------------------------+
                                             ↓
+-----------------------------------------------------------------------------------------+
|                                CANDIDATE OUTPUT CONTRACT                                |
|  - Candidate Generation Constitution & Pure CandidateOutput Schema 유형 명세               |
+-----------------------------------------------------------------------------------------+
```
