2. CORE SECURITY & SOVEREIGN INVARIANTS SATISFIED
--------------------------------------------------------------------------------
1. Zero Direct Trust in LLM Claims:
   - LLM `role.entityId` is never directly trusted as canonical ID.
   - LLM `event.provenance` is never blindly promoted to verifiedEventId.
   - Resolvers (resolveNpcIdentity, resolveInventoryItemIdentity, findAuthoritativeEvent)
     strictly query CanonicalState, UniversalKnowledgeGraph, and HistoricalRecords.
2. Scoped Event Support:
   - Initial bridge support is strictly limited to PICKUP and GIFT.
   - Unsupported or ungrounded events return REJECTED and fail closed.
3. Validator Authority:
   - EngineValidator authority, rules, and gates are completely preserved without
     any relaxations or modifications.
4. Fail-Closed Handling:
   - Ambiguous, novel without proof, or ungrounded semantic events fail closed
     before/at EngineValidator validation.
